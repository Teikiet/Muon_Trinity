CORSIKA 8 Overview
==================

CORSIKA 8 is a modular framework for simulating particle cascades in
astroparticle physics and astrophysical contexts. It emphasizes flexible,
compile-time composition of physical processes together with validation and
computational efficiency.

Getting Started
---------------

The `project repository <https://gitlab.iap.kit.edu/AirShowerPhysics/corsika>`_
contains installation instructions, container releases, standard applications,
and build examples. The sections in this manual describe the framework's core
concepts, available modules, and C++ API.

For contributor requirements, see :doc:`../code/contributing` and the
`usage and collaboration agreement <https://gitlab.iap.kit.edu/AirShowerPhysics/corsika/blob/main/usage_and_collaboration_agreement.md>`_.
