Python Library
==============

The CORSIKA 8 Python library reads simulation output libraries and provides
access to their configuration, summary data, and module output. It is the
recommended interface for analysis workflows that use pandas or Apache Arrow.

Installation instructions and a minimal ``corsika8.io.Library`` example are
maintained in the `Python library README <https://gitlab.iap.kit.edu/AirShowerPhysics/corsika/blob/main/python/README.md>`_.
Additional runnable scripts are available in the
`Python examples directory <https://gitlab.iap.kit.edu/AirShowerPhysics/corsika/tree/main/python/examples>`_.

See :doc:`../framework/output` for the layout of a CORSIKA output library and
:doc:`applications_and_examples` for programs that generate one.
