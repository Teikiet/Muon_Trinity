Getting Started
===============

CORSIKA 8 can be used from a pre-built Apptainer container or built from source.
The repository README is the maintained source for prerequisites, installation,
container releases, and the first run of the standard air-shower application.

* `Install CORSIKA 8 from source or use a container <https://gitlab.iap.kit.edu/AirShowerPhysics/corsika/blob/main/README.md#installation>`_
* :doc:`Review the dependency overview <dependencies>`
* :doc:`Run a standard application or an example <applications_and_examples>`
* :doc:`Read simulation output with Python <python_library>`

For the framework concepts behind a configuration, continue with
:doc:`../framework/modules`, :doc:`../framework/media`, and
:doc:`../framework/particle_stack`.
