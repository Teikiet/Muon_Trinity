A1. REFERENCE INPUT: the table stores CUMULATIVE tau, not local alpha
--------------------------------------------------------------------------------
A1.1 The original wording ("log-linear interpolation of the tabulated
extinction") was WRONG and is withdrawn: the file contains the cumulative
optical depth tau(lambda, z) on a 105-lambda (180..700 nm, 5 nm) x 51-node
vertical (0..50000 m, 1000 m) grid. There is no tabulated alpha, and no
logarithmic quantity is interpolated.

A1.2 DERIVATION OF alpha (explicit).  With nodes z_k = 1000k m (k = 0..50) and
T_k(lambda) the tabulated cumulative optical depth at node k, the local
extinction is the zero-order-hold panel slope

        s_k(lambda) = ( T_{k+1}(lambda) - T_k(lambda) ) / 1000        k=0..49
        alpha(lambda, z) = s_k       for  z_k <= z < z_{k+1}

dz = 1000 m > 0, so no division can be by zero. No log, no exp and no
interpolation of alpha inside a panel: the panels are the model.

A1.3 ZERO HANDLING (explicit).
  (a) s_k == 0 exactly is a legitimate transparent panel: it contributes zero
      and needs no special case. No "zero-to-log" hazard exists, because the
      reference never takes a logarithm of the tabulated data.
  (b) Any non-finite T_k is a HARD FAILURE reported under C4; never silently
      mapped to zero.
  (c) Windows lying fully outside the support return alpha_ref = 0 EXACTLY
      (not "epsilon", not a clamp): see A1.5.

A1.4 WINDOWED (MODEL) EXTINCTION.  The production model evaluates a 50 m box
average, so the reference MUST evaluate the same physical model:
        lo(z) = max(0, z - 25),  hi(z) = min(50000, z + 25),  d(z) = hi - lo
        alpha_ref(lambda, z) = (1/d(z)) * INT_{lo(z)}^{hi(z)} alpha(lambda,t) dt
computed by INDEPENDENT nested numerical quadrature splitting at every z_k
inside [lo,hi], with NO use of s_j*w_j, the two-bin overlap, the +-25 m weight
table, M1, M2 or any production panel machinery.

A1.5 PROFILE BOUNDARIES (explicit).  Normalisation is by the COVERED window
length, not by 50 m:
        z <= 25        : d = z + 25        (window truncated at z = 0)
        25 < z < 49975 : d = 50            (full window)
        z >= 49975     : d = 50025 - z     (window truncated at z = 50000)
        z >= 50025 or z <= -25 : d <= 0 -> alpha_ref = 0 exactly.
This mirrors the production model's own normalisation deliberately and is
stated so the reference is not silently a DIFFERENT model; any departure would
confound the comparison with a definitional difference.
