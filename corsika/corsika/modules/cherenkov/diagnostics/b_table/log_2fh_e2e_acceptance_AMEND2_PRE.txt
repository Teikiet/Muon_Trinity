A7. alpha_scale FIXED BEFORE THE RUN (C8(ii) only)
--------------------------------------------------------------------------------
A7.1 DEFINITION (algorithmic, deterministic, fixed now):
      alpha_scale := max over all 81 lambdas in {300,305,...,700} nm and all
                     heights h in {-100, -99, ..., 50100} m (1 m steps) of
                     | sum_j s_j(lam) * w_j(h) |
      with a floor of 1.0e-30 if the maximum is identically zero.
      It is a property of the tabulated input and the model, not of the
      comparison, and it is computed from the same functional being compared.
A7.2 C8(ii) BOUND IS ABSOLUTE AGAINST THAT SCALE:
                     max | alpha_prod - sum_j s_j w_j |  <=  1.0e-12 * alpha_scale
      It is deliberately NOT a pointwise-relative bound, to avoid amplification
      wherever the sum happens to be near zero.
A7.3 REPORTED AS INFORMATION (not gated): the max pointwise relative deviation
      restricted to points with |sum_j s_j w_j| >= 1.0e-3 * alpha_scale; the
      number of grid points compared; and the (lambda, h) location attaining
      alpha_scale.
A7.4 EXPECTED ORDER (expectation, NOT a criterion): alpha_scale ~ 1e-3 m^-1,
      i.e. the largest extinction at the shortest wavelengths near the surface.
      The run reports the measured value and its location; a value differing by
      orders of magnitude is reported and the criterion is unchanged.
